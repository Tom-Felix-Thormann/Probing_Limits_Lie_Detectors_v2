Azaria, A., & Mitchell, T. (2023) The Internal State of an LLM Knows When It’s Lying. In Findings of the Association for Computational Linguistics: EMNLP 2023, pages 967–976 [https://aclanthology.org/2023.findings-emnlp.68/](https://aclanthology.org/2023.findings-emnlp.68/)
